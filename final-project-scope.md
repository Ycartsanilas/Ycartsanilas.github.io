# Project Scope Statement

## Project Name
Poetic Injustice - Roller Skating

## Project Purpose
The purpose of this project is to create a website that encourages others to take an interest in roller skating.  Through sharing my passion and personal experiences, I hope to inspire others to explore roller skating as a recreational activity that promotes mental, spiritual, and physical wellness.

## Description
This project will consist of a two-page website dedicated to roller skating as a recreational activity and a sport that requires speed, agility, and precision.  My intended audience will include beginner skaters, individuals who skated as children and wish to return to the hobby, and anyone interested in incorporating roller skating into their fitness routine.

## Desired Results
- **Home Page (index.html):** Introduce roller skating as both a recreational activity and a sport, discuss its mental, spiritual, and physical benefits, and encourage beginner and returning skaters to pursue the hobby.
- **About Page (about.html):** Share my personal skating journey, how my perception of roller skating has evolved, and offer encouragement to beginner and returning skaters.
- **Navigation:** Include functioning links between the homepage and the about page.
- **Stylesheet (style.css):** Create a single external stylesheet that applies consistent styling to both HTML pages.
- **GitHub Repository:** Create a single public repository containing all website files and project documentation.
- **README.md:** Explain the project's purpose and provide the links to the live website and the documentation folder.
- **Documentation (docs/):** Include the following three Markdown files:
    - **scope.md:** Revised Project Scope Statement incorporating peer feedback from Assignment 04.
    - **plan.md:** Project plan containing TAME risk analysis and task schedule.
    - **retrospective.md:** Reflection on the project process.

## Exclusions
- Additional web pages beyond the two required pages.
- Instructional skating videos or tutorials.
- Online sales of roller skates or equipment.
